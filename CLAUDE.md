# Claude Code repository instructions

Before inspecting, editing, building, packaging, or publishing this repository, read and follow:

- `AGENTS.md`
- `LICENSE`
- `LICENSE_SCOPE.md`
- `NOTICE`
- `CONTRIBUTING.md`
- `LOCAL-WORKER.md`
- `docs/licensing.md`

`AGENTS.md` contains the repository-wide operational constraints. Do not treat public source availability as open-source permission, do not broaden the license, and do not publish excluded or competition-sensitive material. Run `python scripts/check_license_policy.py` after any licensing, provenance, packaging, release, or agent-instruction change.
