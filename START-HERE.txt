SOURCE CHECKOUT - existing Windows route
Install a supported 64-bit Python with Tk as described in the README, then run:
  python scripts/bootstrap.py --launch
Read-only repeat check: python scripts/bootstrap.py --check --desktop
The script finds its own checkout, even when called from another directory.
Setup may need internet access to install dependencies. The public synthetic
example must not require private team data, an AI account or hardware.

Consult exact PR/check evidence; documentation alone is not completion proof.

The fused course has a documented geometry mismatch; use synthetic geometry
for coherent demonstrations. The lap model, four-wheel experiment and torque
receipt viewer have different scopes. Synthetic results and software tests do
not establish real-car accuracy or validated torque-control gains.
No new team data are available. Normal simulator startup must not connect to
or flash a board, transmit CAN commands or operate vehicle hardware.
