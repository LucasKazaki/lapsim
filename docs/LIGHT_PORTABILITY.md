# Light simulator reproducibility: source preparation

Status: **source-only candidate, not built, tested or runnable as an app**.
The original process-observation denial remains in force; no tests, process
probes, physics, solver, helper, server or lease action were launched here.
Historical budgets, source snapshots and accepted evidence are unchanged.
This is a source-preparation supplement to the
[technical master](EV_SIMULATOR_MASTER.md), not a new run result.

The [portable core candidate](../research/light/portable-core-candidate/README.md)
closes a specific source dependency problem: the coupled plant can be isolated
from eager optimizer/UI imports and unrelated tire-coefficient files. Its
unique package has nine scientific modules plus an exact scalar-validation
helper and inert initializer. Only two scientific import lines change in this
new candidate. The active `src/` package is not replaced. An import graph and
source hashes are supplied for review; they are not execution evidence.

The plant port does not by itself port the driver, line producer or guarded
supervisor. The generic actuation implementation still exposes non-AWD options;
the requested campaign must explicitly require four-motor AWD rather than rely
on defaults. Regen remains excluded until its low-speed/lag/charge/brake-domain
issues receive a separate justified correction and qualification.

## Rights and environment gates

The portable core has no declared external runtime package. Its proposed build
tool is not yet exactly locked or executed. The line producer separately needs
NumPy/SciPy; the source tree's broad dependency declarations are not a verified
numerical lock and must not be installed implicitly. The earlier kernel import
graph and original archive are not automatically equivalent to this package.

The [AMZ input provenance](../research/light/portable-course-inputs/PROVENANCE.json)
pins the public source and MIT notice, with raw and line-ending-normalized hashes.
The processed course has assumed width and absent surveyed boundaries. It is
not official event geometry, a certified corridor or the optimized racing line.
No private authenticated line/promotion bundle, local runtime transcript, tire
coefficient file with unverified rights, TTC table or team image is published.

The complete project remains an incomplete public backup. Privacy-safe portable
execution records and a clearly licensed, reviewed dependency closure still need
work. Source publication and proposed packaging do not establish a reproducible
run, car calibration, official points, tournament coverage or a winner.
