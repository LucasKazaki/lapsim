# Source and rights boundary

This candidate contains project scientific source, not vendored solver code or
third-party tire tables. Per-file original and candidate hashes are recorded in
`SOURCE_MANIFEST.json`. Publication is authorized by the repository owner; no
new project-wide license grant is invented by this packaging metadata. Confirm
the repository's intended license and every contributor's rights before claiming
that all repository contents have a uniform redistribution license.

The numerical tire assumptions in this boundary are the project's synthetic
planar model. The UPC/Pacejka coefficient sources, tire `.tir` files, TTC data,
team telemetry, photographs and private execution receipts are not included.
The bundled public LF AMZ simulator map/cone inputs under
`src/lapsim_light_course/data/` retain their own MIT notice and exact source
provenance. Their constructor still takes explicit consumer-supplied bytes.
That license must not be represented as licensing all other project source or
validating the geometry. Independent admitted racing-line/producer evidence is
supplied separately and is not included here.
